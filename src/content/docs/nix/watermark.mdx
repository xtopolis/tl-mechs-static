Your item level growth is driven by a hidden **watermark**: the average of the
highest item level you have *ever dropped* in each of the three categories —
**weapon**, **armor**, and **accessory**. It doesn't matter whether you equip,
bank, or sell the item; only the drop counts. Any single drop can be at most
**watermark + 1**, so if one category lags it holds the others back — the
highlighted card shows which to farm next.

:::tip[Weapon]
Run **Hall of Illusion** — the fastest source of weapon drops. Difficult mode is
fine if Nightmare is too tough. Roughly a **6.7%** chance to drop a weapon.
:::
